# Guia de Organização de Imagens - FEU Engenharia & Soluções

Esta pasta contém todos os placeholders de imagens organizados por seção.
Todas as imagens reais foram preparadas para você substituir manualmente com extrema facilidade.

## Como Substituir pelas Fotos Reais:
1. Copie suas imagens reais para as respectivas pastas listadas abaixo.
2. Você pode renomear sua foto para o mesmo nome do placeholder (ex: `hero-1.jpg`), ou usar o arquivo que preferir e atualizar o caminho no `index.html`.
3. As proporções recomendadas abaixo garantem a melhor harmonia visual.
